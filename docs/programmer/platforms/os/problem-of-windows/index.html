    3. 切换鼠标滚轮方向#

    以下是在 Windows 11 中修改滚轮（鼠标或触摸板）滚动方向的几种方案汇总，包括系统设置、注册表和第三方工具方法，帮助你根据使用习惯选择最合适的方式。

    概览#

    • 触摸板滚动方向：Windows 11 内置支持反转触摸板滚动方向，仅适用于精密触摸板设备，无需动用注册表或外部工具。 (Windows 11 反转鼠标和触摸板滚动方向原创 - CSDN博客)

    • 鼠标滚轮方向：系统默认不提供 UI，需通过修改注册表键值 FlipFlopWheel 或使用第三方软件来实现。 (Windows通过注册表改变鼠标滚轮和触摸板的滚动方向转载 - CSDN博客, How to enable reverse mouse and touchpad scrolling on Windows 11)

    • 第三方工具：例如 Winaero Tweaker 可一键切换自然/传统滚动模式，无需手动改注册表。 (Windows 11 will allow you to easily change mouse wheel scrolling …)

    一、反转触摸板滚动方向#

    1. 按 Win + I 打开「设置」。
    2. 在左侧点击 蓝牙和设备，再选择 触摸板。
    3. 在 滚动和缩放 下拉选项中，将滚动方向设置为：
      • 向下移动时向上滚动：传统模式
      • 向下移动时向下滚动：自然（反向）模式 (Windows 11 反转鼠标和触摸板滚动方向原创 - CSDN博客)

    触控板一般提供设置中直接设置 - 仅精密触摸板设备提供此选项，如不可用可使用设备厂商驱动程序或第三方软件进一步定制。

    二、通过注册表修改鼠标滚轮方向#

    Windows 11 没有内建 UI 选项反转鼠标滚轮，因此可按如下步骤手动修改注册表键值：

    1. 打开注册表编辑器
      • 按 Win + R，输入 regedit 并回车。 (Windows通过注册表改变鼠标滚轮和触摸板的滚动方向转载 - CSDN博客)
    2. 定位到设备参数
      • 导航至：
        HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\HID
      • 展开与鼠标 VID ／ PID 相匹配的子项，找到 Device Parameters。 (Windows通过注册表改变鼠标滚轮和触摸板的滚动方向转载 - CSDN博客)
    3. 修改 FlipFlopWheel
      • 在右侧找到 FlipFlopWheel（DWORD 32 位）。
      • 双击并设置数值数据：
        • 0 → 传统滚动（向下滚动时页面下移）
        • 1 → 自然滚动（向下滚动时页面上移） (How to enable reverse mouse and touchpad scrolling on Windows 11)
    4. 重启生效
      • 完成后关闭注册表，重启电脑或拔插鼠标以应用更改。 (Windows通过注册表改变鼠标滚轮和触摸板的滚动方向转载 - CSDN博客)

    注意：若有多个鼠标设备，请确认所修改项对应当前使用的设备，可在「设备管理器」查看并比对“设备实例路径”。

    一、通过设备管理器查看#

    1. 打开设备管理器#

    1. 按 Win + X，选择 设备管理器。
    2. 或者按 Win + R 输入 devmgmt.msc 并回车打开。 微软技能学习

    2. 找到鼠标设备#

    1. 在列表中展开 鼠标和其他指针设备 (Mice and other pointing devices)。
    2. 如果 G304 以 HID 设备形式出现，也可在 人机界面设备 (Human Interface Devices) 下查找。 Super User

    3. 查看硬件 ID#

    1. 右键点击对应项，选择 属性 (Properties)。
    2. 切换到 详细信息 (Details) 页签。
    3. 在 属性 (Property) 下拉菜单中选择 硬件 Ids (Hardware Ids)。 微软技能学习

    三、使用 PowerShell 脚本（可选）#

    部分社区用户分享了使用 PowerShell 一键切换滚动方向的方法，原理同样是修改 FlipFlopWheel 注册表值。示例脚本可在管理员模式下运行，省去手动操作的麻烦。 (Reverse Mouse Wheel scroll in Windows 11 - Gist - GitHub)

    # Reverse Mouse Wheel scroll  in Windows 11
Chose between natural mode like MacOS or Windows default mode.

## Step 1: Open Windows PowerShell in Administrator Mode.
You can do this by going to Start Menu, type PowerShell, and click Run as Administrator.

## Step 2: Copy the following code and paste it in the command line of Windows PowerShell:

$mode = Read-host "How do you like your mouse scroll (0 or 1)?"; Get-PnpDevice -Class Mouse -PresentOnly -Status OK | ForEach-Object { "$($_.Name): $($_.DeviceID)"; Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Enum\$($_.DeviceID)\Device Parameters" -Name FlipFlopWheel -Value $mode; "+--- Value of FlipFlopWheel is set to " + (Get-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Enum\$($_.DeviceID)\Device Parameters").FlipFlopWheel + "`n" }

The code above is one-liner PowerShell script. Copy-paste it as-is.

## Step 3: It will ask how do you like your mouse to scroll.

Downward wheel motion makes the page...

    0 - Move up so you see contents below (Default Mode, Windows behavior)

    1 - Move down so you can see contents above (Natural Mode, Mac behavior, reverse mode)

Type the number that corresponds to your scroll preference.

## Step 4: Restart your computer.
Your settings will take effect after you restart.

    四、常见疑问#

    • 设置后无效怎么办？
      • 请确认修改的 FlipFlopWheel 位于当前鼠标对应的 Device Parameters 路径下，并重启或重新连接设备。 (Windows通过注册表改变鼠标滚轮和触摸板的滚动方向转载 - CSDN博客)
    • 多设备切换
      • 若电脑同时连接多个鼠标，需分别为每个设备改注册表或使用支持多设备管理的第三方工具。

    4. Docker#

    安装Docker提示 Exising installation is up to date 解决方法(Docker 莫名其妙消失)#

    • 按下Window+R唤起命令输入界面，输入regedit打开注册表编辑
    • 路径HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Docker Desktop
    • 将整个Docker Desktop组点击右键删除
    • 重新安装

    5. 文件权限#

    ✅ 用 PowerShell 手动设置权限**#

    1. 在 PowerShell 中运行以下命令设置正确权限：
    icacls aliyun-sg-adnetwork.pem /inheritance:r
icacls aliyun-sg-adnetwork.pem /grant:r "$($env:USERNAME):R"

    解释：

    • /inheritance:r 是移除继承权限
    • /grant:r "$env:USERNAME:R" 是仅授予你当前用户读取权限
