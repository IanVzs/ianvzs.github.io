    软件只有deb怎么办#

    sudo dnf install distrobox
distrobox create --name deb-apps --image ubuntu:latest

distrobox enter deb-apps # 等待漫长的安装
# 进入主机的下载文件夹（容器自动挂载了主机文件）
cd ~/Downloads
# 安装deb
sudo dpkg -i cursor*.deb
# 修复依赖
sudo apt update && sudo apt -f install -y
# 导出
distrobox-export --app cursor

    完事！

    执行：

    fc-list | grep -i "JetBrains Mono"

    预期结果：

    • 输出多行字体文件路径（例如 JetBrainsMono-Regular.ttf、JetBrainsMono-Bold.ttf 等）

    第 3 步：修改 Cursor 用户设置#

    打开文件：

    • ~/.config/Cursor/User/settings.json 确保存在以下配置（可直接复制）：

    说明：

    • 如果你的 settings.json 里还有其它配置，不要删除它们，只需新增/覆盖上面 3 项。

    1. Ctrl + Shift + P
    2. 输入并选择 Developer: Reload Window 如果仍未生效，重启 Cursor 即可。

    输入法#

    从你的描述看，你在 Fedora 通过 RPM 安装后，遇到了两个常见问题：一是找不到启动图标，二是无法唤起中文输入法

    🚀 问题一：启动图标在哪？#

    RPM 包安装时，通常会帮你创建好一个桌面启动图标。

    • 系统级图标位置：通用的 .desktop 启动文件通常位于 /usr/share/applications/ 目录下。
    • 用户级图标位置：如果你只为当前用户安装，文件可能在 ~/.local/share/applications/ 目录。
    • 如何找到它：
      1. 打开你的文件管理器。
      2. 在地址栏输入 /usr/share/applications/ 并回车。
      3. 在文件列表中找到名为 wechat.desktop 或类似名称的文件。

    ⌨️ 问题二：无法唤起中文输入法？#

    微信举例: wechat

    这个问题主要是因为微信启动时没有继承正确的输入法环境变量，导致无法与输入法框架（如你正在使用的 fcitx）通信。解决方法很简单：修改微信的 .desktop 启动文件，在启动命令中注入所需的环境变量。 下面是详细的操作步骤：

    1. 定位启动文件： 首先，根据上面的方法，找到微信的 .desktop 文件。通常是 /usr/share/applications/wechat.desktop。如果不在那里，也可以检查 ~/.local/share/applications/ 目录。

    2. 编辑文件： 用管理员权限和文本编辑器打开它。可以在终端中运行以下命令：

      sudo nano /usr/share/applications/wechat.desktop

    3. 修改 Exec 行： 在文件中找到以 Exec= 开头的行。你需要在这行的命令前添加三个环境变量。

      • 修改前：

        Exec=/usr/bin/wechat %U

      • 修改后：

        Exec=env GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx XMODIFIERS=@im=fcitx /usr/bin/wechat %U

      • 代码说明：

        • GTK_IM_MODULE=fcitx：告诉使用 GTK 框架的程序调用 fcitx。
        • QT_IM_MODULE=fcitx：告诉使用 QT 框架的程序调用 fcitx。
        • XMODIFIERS=@im=fcitx：这是较传统的 X11 输入法设置方式，作为双重保障。
        • env：是一个命令，用于在启动 /usr/bin/wechat 之前设置这些环境变量。

    4. 保存并退出

    5. 重启App
